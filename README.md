# Video Editing API (fmov + FastAPI)

Lightweight video editing service for Leapcell (512MB-1024MB). Editly-style JSON API.

## Features

- **Text overlays** (custom fonts, colors, positions)
- **Image overlays** (logos, watermarks)
- **Audio mixing** (background music, sound effects)
- **JSON-based** (like Editly - send config, get video)
- **File uploads** supported
- **512MB memory optimized** (fmov + PIL, no heavy deps)
